# Security policy

AEGIS 0.2 is a **non-destructive development preview** and should not be used
to secure or install a production machine. No releases are designated stable.

Do not publish encryption keys, machine passwords, TPM PINs, private signing
keys or real-world sensitive identifiers in public issues or logs.

Until a project maintainer provides a verified private security contact, do
not publish detailed exploit steps involving undisclosed vulnerabilities in
public issues. Use GitHub's private vulnerability reporting feature if enabled,
or request a confidential contact through a minimal non-sensitive issue.

Vulnerability responses, security fixes and supported-release commitments
will be documented before the first public production release.
